# Transaction Processing API

An educational FastAPI project for learning how to build a transaction
processing service. This repository currently contains only the initial project
structure; no API endpoints have been implemented.

## Requirements

- Python 3.11 or newer

## Setup

Create and activate a virtual environment, then install the project and its
development dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
```

## Tests

Once tests have been added, run them with:

```bash
pytest
```

The `app` package will contain application code, and the `tests` package will
contain automated tests.
